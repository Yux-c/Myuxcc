# Myuxcc

[中文](./README.md) | [English](./README_EN.md)

原生、轻量、零依赖的 macOS 全能截图效率工具。集**区域截图、标注编辑、滚动长截图、离线 OCR、原位截图翻译、区域录屏、桌面钉图**与**剪贴中转板**于一体。

基于 `Swift` + `AppKit` + `ScreenCaptureKit` + `Vision` + `Translation` 原生构建，不依赖任何第三方框架。

## ✨ 核心特性

| 模块 | 功能亮点 |
|---|---|
| **快速截图** | 全局热键（默认 `⌃A`）瞬间冻结多显示器画面；支持智能窗口吸附、11×11 像素放大镜与 sRGB 取色（按 `C` 复制色值）、自由框选与 8 手柄微调 |
| **丰富标注** | 矩形、椭圆、箭头、画笔（支持手绘直线自动拉直）、荧光笔、文字、马赛克；提供 8 色与 3 档粗细调节、PPT 式选中移动/缩放、多步撤销重做（`⌘Z` / `⇧⌘Z`）及数字键 `1`–`9` 快捷切换 |
| **滚动长截图** | 锁定选区后手动上下滚动即可实时拼接；自动识别并剔除吸顶栏、吸底栏、固定侧边栏与悬浮按钮，支持回滚修正与实时长图预览 |
| **离线 OCR** | 基于系统 Vision 框架本机识别中英文，无需联网；支持在原图文字上直接按住拖拽划选、双击选词、三击选行与一键复制 |
| **截图翻译** | 基于系统 Translation 框架本机离线翻译（需 macOS 26+）；支持**原位覆盖译文**（自动采样背景底色与文字颜色回填，按 `T` 随时切换原文/译文）与**文本对照翻译** |
| **桌面钉图** | 将选区或译图一键钉在桌面置顶参考；支持滚轮/捏合缩放、`⌥`+滚轮调节透明度、右键随时二次 OCR / 翻译 / 保存 |
| **区域录屏** | 选区直录 H.264 MP4（Retina 原生像素分辨率，最高 30 fps，画面静止时自动省帧），录制框与计时控制条不入镜 |
| **剪贴中转板** | 默认按 `⌃X` 或拖拽文件时左右晃动鼠标呼出；融合**剪贴板历史**（文字/图片/文件）与**文件暂存架**，支持关键词搜索、空格大图/全文预览、点击直接自动粘贴并恢复原剪贴板、拖拽跨应用发送 |

## 🚀 构建与安装

### 1. 直接下载安装包
前往 [GitHub Releases](https://github.com/Yux-c/Myuxcc/releases) 下载最新版的 `Myuxcc-macos-universal-*.dmg`（同时支持 Apple Silicon 与 Intel），双击打开并将 `Myuxcc.app` 拖入 `Applications` 文件夹即可。

> **首次打开提示**：由于未进行 Apple 付费开发者公证，首次运行如遇系统拦截，可在终端执行：
> ```bash
> xattr -cr /Applications/Myuxcc.app
> ```
> 或在「系统设置 › 隐私与安全性」中点击「仍要打开」。

### 2. 从源码构建
**环境要求**：macOS 14.0+，Xcode Command Line Tools。

```bash
# 编译 Release 版本并自动安装到 /Applications/Myuxcc.app
./build.sh

# 启动应用
open /Applications/Myuxcc.app
```

> 仅编译不安装可执行 `./build.sh --no-install`。首次使用截图与自动粘贴功能时，请按提示在「系统设置 › 隐私与安全性」中授予**屏幕与系统录音**及**辅助功能**权限。

## ⌨️ 常用快捷键

| 快捷键 | 功能 |
|---|---|
| `⌃A` | 触发截图 / 停止当前录屏（可在设置中自定义） |
| `⌃X` | 打开 / 收起剪贴中转板（可在设置中自定义） |
| `↩` / `⌘C` / 双击 | 复制选区截图到剪贴板 |
| `⌘S` | 保存截图到指定目录 |
| `1` – `7` | 依次切换：矩形、椭圆、箭头、画笔、荧光笔、文字、马赛克 |
| `8` / `9` 或 `⌘Z` / `⇧⌘Z` | 撤销 / 重做标注操作 |
| `⇧`（按住绘制） | 约束正方形 / 正圆 / 45° 箭头 |
| `C` | 框选前复制光标处 sRGB 色值 |
| `T` | 在已翻译的钉图上切换显示「原文 / 译文」 |
| `Space` | 在剪贴中转板选中条目上打开 / 关闭左侧预览栏 |
| `Esc` | 取消选中标注 / 退出截图 / 结束长截图 / 关闭钉图 |

## 📂 目录结构

- `Sources/Myuxcc/`：核心源码（截图会话、标注引擎、长截图拼接算法、OCR 与子进程守护、原位翻译、录屏、`Shelf/` 剪贴中转板）
- `Icon/`：CoreGraphics 应用图标生成脚本与资源
- `build.sh`：一键编译、签名与安装脚本
