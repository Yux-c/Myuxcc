# Myuxcc — 截图、录屏与剪贴中转板

独立编写的 macOS 截图工具（Swift + AppKit + ScreenCaptureKit），零第三方依赖。
应用图标和菜单栏图标由 CoreGraphics 绘制（见下文「图标」），界面里其余图标使用系统 SF Symbols。

## 功能（MVP）

| 功能 | 操作 |
|---|---|
| 菜单栏常驻 | 菜单栏相机图标 → 截图 / 剪贴中转板 / 设置 / 退出 |
| 全局快捷键 | 默认 `⌃A`，可在设置里改（全局注册，运行期间其他应用里的同一组合会被截走，`⌃A` 即「移到行首」；组合被其他应用占用时设置里红字提示） |
| 设置 | 菜单栏图标（左键或右键）→「设置…」，或应用在前台时按 `⌘,`：登录时自动打开、截图快捷键（点输入框后按新组合，须含 ⌃/⌥/⌘，Esc 取消，可一键恢复 ⌃A）、保存位置（选择文件夹 / 在访达中显示）、录屏位置（默认 `~/Movies/Myuxcc 录屏`，可改）、长截图录帧开关与记录文件夹、剪贴中转板（打开快捷键、最多保留个数、是否记录剪贴板、辅助功能授权、一直显示预览栏、晃动打开 / 再晃关闭与灵敏度、清空、在访达中打开） |
| 冻结屏幕 + 多显示器 | 触发瞬间截下所有屏幕，在冻结画面上框选 |
| 窗口吸附 | 悬停自动高亮光标下的窗口（桌面空白处为整屏），单击选中；拖动超过 4pt 取消吸附改为手动框选；双击直接复制该窗口 |
| 放大镜 | 光标右下角显示 11×11 像素放大、像素坐标、sRGB 色值；靠近屏幕边缘自动翻转；按 `C` 复制色值并退出 |
| 框选 | 拖拽选区；显示像素尺寸；8 个手柄调整；拖动选区移动；右键清除选区 / 再右键退出 |
| 标注 | 矩形、椭圆、箭头、画笔、荧光笔、文字、马赛克（再点一次工具按钮回到调整选区模式）；按住 `⇧` 画正方形 / 正圆 / 正方马赛克，箭头吸附到 45° 的倍数 |
| 工具栏位置 | 只由选区决定：放在选区下方，下方放不下就放上方，上下都放不下（选区接近全屏）就放在选区内底部；右边与选区对齐，贴左右屏幕边时收进屏幕内。工具栏在上方时尺寸标签移进选区左上角 |
| 颜色 / 粗细 | 选了工具或选中标注时，样式条紧贴工具栏出现（左边对齐），放在工具栏远离选区的一侧，那一侧碰到屏幕边就换到另一侧；出现、收起都不会让工具栏挪位置。样式条内容：8 种颜色 + 细 / 中 / 粗（当前选中的颜色和粗细都用浅色圆角底块标出，不用颜色表示选中，免得和色板混淆）（线宽 2 / 3 / 6 pt，荧光笔 10 / 16 / 24，文字 14 / 20 / 30 pt）；选中标注时改它（可撤销），同时作为之后新标注的样式；荧光笔单独记一种颜色（默认黄色，半透明）；选择在多次截图之间记住；马赛克没有样式 |
| 编辑标注（类似 PPT） | 单击标注选中（虚线框 + 手柄），拖动移动；拖手柄缩放，箭头拖两端；`⌫`/`⌦` 删除；方向键微调 1pt（`⇧` 10pt）；双击文字重新编辑；新画的标注自动选中；`Esc` 先取消选中，再按才退出 |
| 撤销 / 重做 | `⌘Z` / `⇧⌘Z` 或工具栏按钮；移动、缩放、删除、微调、改文字都能撤销 |
| 数字键 | 框选后按 `1`–`9` 依次按下工具栏从左数第 1–9 个按钮：`1`–`7` 为矩形、椭圆、箭头、画笔、荧光笔、文字、马赛克（再按一次取消工具），`8` 撤销，`9` 重做；按钮不可用时提示音。悬停按钮的提示里有对应数字。输入文字时数字照常输入 |
| 复制 | `↩` / `⌘C` / 双击选区 / ✓ 按钮，PNG + TIFF 写入剪贴板。还没框选、鼠标停在窗口上（窗口已高亮）时直接按 `↩` 或 `⌘C` 就截这个窗口，`⌘S` 则直接保存，不用先点一下选中 |
| 保存 | `⌘S` 或工具栏，保存到设置里的保存位置（默认桌面；所选文件夹不存在时回落到桌面）`截图 yyyy-MM-dd HH.mm.ss.png`（同一秒内多次保存自动追加 `-2`、`-3` 后缀，不会覆盖） |
| 长截图 | 框选后点工具栏「长截图」（标注前可用）：区域锁定，覆盖窗变透明，自己滚动底下的应用即可自动拼接，上下都可以滚（往上滑超出已截范围时在长图顶部补行，滑回已截部分不影响结果）；HUD 显示进度和提示（滚太快会提示向上回滑），右侧实时预览（随长度变高，到选区高度或 480 pt 封顶后滚动显示最新部分）；`↩` 复制、`⌘S` 保存为 `长截图 …png`、`Esc` 取消（长截图期间注册为全局快捷键，点过被截应用也能用）。吸顶栏只保留一次，吸底栏和悬浮在内容上的固定元素（如「回到最新」按钮，不透明或半透明）只在末尾出现一次；侧边吸附的面板或导航栏（内容滚动时原地不动的整列）只按第一屏的样子出现一次，下方用面板下的背景填充；连续多帧对不上（滚太快 / 丢帧）时会在长图末尾自动另起一段并提示「中间可能缺一段」，不会一直卡住；选区尺寸中途变化会停止抓帧并提示重新开始 |
| 识别文字（OCR） | 框选后点工具栏「识别文字」（长截图按钮右边），或钉图右键「识别文字」：原图直接贴在屏幕原位，用系统 Vision 在本机识别简体 / 繁体中文和英文，识别完成后可直接用鼠标在原图文字上按住拖拽逐字或跨行框选文字（支持双击选词、三击选整行、`⌘A` 全选、`⌘C` 复制选中文字，右键菜单可复制选中文字或全部文字）。应用启动 5 秒后在后台预热一次识别模型 |
| 截图翻译 | 框选后点工具栏「截图翻译」（识别文字按钮右边）：选区钉在桌面上，先识别文字、合成段落，再用系统 Translation 框架在本机翻译，把每段原文用周围的底色盖住，按原来的字色、差不多的字号写上译文（太长时缩小字号、换行），语言和用时显示在钉图下方单独一条（缩放、拖动时跟着走，不压住译文；下方放不下时放到上方），约 2.5 秒后自己消失；钉图上按 `T` 或右键「显示原文 / 显示译文」切换，复制、保存、识别的都是正在显示的那张。钉图右键「翻译」可以给已有钉图覆盖译文。要文字版译文：「识别文字」窗口里点「翻译」，译文显示在原文下方，逐行翻译、空行和 Tab 分栏保持原样，改过原文再点「翻译」按改过的翻，`⌘↩`「复制译文」。默认中英互译（以中文为主的文字译成英文，其他译成简体中文；中英混排按汉字占比判断），文字窗口里可以固定「译成简体中文 / 译成英文」，覆盖翻译也照这个设置。实测一张小图识别加翻译加绘制约 0.1–0.3 秒 |
| 钉图 | 工具栏图钉；拖动移动、滚轮/捏合缩放、`⌥`+滚轮调透明度、双击或 Esc 关闭、右键菜单（复制/识别文字/翻译/保存/原始大小/关闭） |
| 取消 | `Esc` |
| 剪贴中转板 | 由同作者的 MacFileRelay 合并而来，兼做剪贴板，界面参照 Maccy。默认按 `⌃X`（设置里可改）或菜单栏「剪贴中转板」打开 / 收起；拖着文件、图片或链接时左右晃两下鼠标，也会在鼠标旁打开（打开时空手再晃一下关闭，可在设置里关掉或调灵敏度）。**布局**：顶部是标题、搜索框和预览开关；中间是条目列表，文字条目只显示第一行并一直排到右边，复制来的图片显示缩略图，文件显示图标和文件名，选中行是系统强调色圆角高亮；面板打开时鼠标在列表左上角，预览栏打开时往鼠标左边展开，列表位置不动；底部是「清空 ⌥⌘⌫」「在访达中打开」「偏好设置… ⌘,」。**键盘**：用快捷键打开时焦点在搜索框，直接打字按名称或文字内容过滤；`↑` `↓` 选择，`↩` 粘贴选中项，`⌘⌫` 删除选中项，`⌥⌘⌫` 清空（先确认），`⌘,` 打开设置，`Esc` 先清空搜索、再收起；点到别处自动收起。**预览栏**：光标停在选中的条目上按空格，列表左边打开预览栏，再按空格关闭（光标不在选中条目上时，空格照常输入搜索框；面板关闭后预览栏也收起），也可以点右上角按钮或在设置里勾选「一直在左边显示预览栏」；显示选中条目的大图 / 全文 / 文件信息和复制时间，带「识别文字」「钉在桌面」「删除」三个按钮。**剪贴板**：复制的文字存成 `剪贴板 ….txt`、图片存成 `剪贴板 ….png`、在访达里复制的文件复制一份进来（合计超过 100 MB 不收；图片超过 5000 万像素不收，TIFF 转 PNG 在后台做），和拖进来的文件按时间排在同一个列表里；同样的内容再复制只移到最前；密码管理器标记为隐私的内容不记录；设置里可以关掉。**点一下任意条目**（或 `↩`）：面板收起，直接贴进正在用的应用的输入框（文字贴成文字、复制来的图片贴成图片、其他贴成文件本身），贴完约 0.8 秒后剪贴板恢复成原来的内容（原来的所有格式都保留；这期间你又复制了别的就不动；连点几条时恢复成第一次之前的内容；恢复动作不会被记成新的一条）。原理是临时把条目放上剪贴板、替你按 `⌘V`，需要「辅助功能」权限（设置 →「允许辅助功能…」）；没允许时只能复制，条目会留在剪贴板上，并提示自己按 `⌘V`。右键「只复制」照旧只放上剪贴板。右键条目：粘贴 / 只复制 / 打开 / 在访达中显示 / 删除。**文件**：拖进来的复制一份暂存（原文件不动），图片数据存成 PNG、网页链接存成 `.webloc`、照片 / 邮件附件等「文件承诺」也能收；按住任意一行拖到微信、邮件或访达即可发送（文字条目拖出去是文字）。默认最多留 50 个（5–100 可调），超出时最早的移到废纸篓，可以恢复；晃动打开的面板在鼠标移出约 0.8 秒后自动收起。文件存在 `~/Library/Application Support/Myuxcc/Shelf/`；启动时会把 MacFileRelay 留下的文件搬过来 |
| 录屏 | 框选后点工具栏「录屏」（长截图按钮右边，标注前可用）：截图界面关闭，选区外围出现红色虚线框，旁边的小条显示录制时长（红点闪烁）、「放弃录屏」和「停止并保存」；录制期间菜单栏图标变成红色录制图标，再按截图快捷键或点菜单栏「停止录屏」也能停止。只录选区里的画面（含鼠标指针，不含声音），按选区的实际像素录（Retina 屏为 2 倍），H.264、最高 30 fps，画面不变时不出帧、结尾静止的部分保留到停止时刻；虚线框和小条本身不会被录进去。默认存到 `~/Movies/Myuxcc 录屏/`（设置里「录屏位置」可改，没有就自动新建），文件名 `录屏 时间.mp4`，录制中先写在临时文件夹，停止后才移过去 |

## 构建与运行

需要 macOS 14+、Xcode 命令行工具。

```bash
./build.sh                      # 产出 build/Myuxcc.app 并装到 /Applications/Myuxcc.app
open /Applications/Myuxcc.app
```

`build.sh` 每次构建完都会用 `/Applications` 里的新副本替换旧的，并在 LaunchServices 里只登记这一份，所以 Myuxcc 会出现在系统的 App 列表（启动台）里；只想构建不安装时用 `./build.sh --no-install`。正在运行的旧进程不受影响，要退出后重新打开才是新版本。两份副本的 bundle ID 和签名相同，屏幕录制等权限不用重新授权；「登录时自动打开」登记的是具体那份 App 的位置，换到 `/Applications` 后要在设置里重新勾选一次。

首次截图会请求「屏幕与系统录音」权限：到 系统设置 › 隐私与安全性 › 屏幕与系统录音 打开 Myuxcc，然后退出并重新打开应用。
macOS 15 起还会弹出「正在请求绕过系统无痕浏览窗口选择器」的确认框（直接调用 ScreenCaptureKit 的应用都会有，并会定期再次询问），需点「允许」。

### 签名

`build.sh` 优先使用登录钥匙串里的自签名证书「ScshootDemo Local Signing」（证书名沿用旧名，签名标识已是 `com.yuxccu.myuxcc`）签名，指定要求为「bundle ID + 证书」，重新构建后屏幕录制权限保持有效。
找不到证书时退回 ad-hoc 签名；ad-hoc 签名绑定二进制哈希，每次重新构建都要重新授权。

### 图标

应用图标是象牙白底板上两块交叠的玻璃板（墨色在后、朱红在前），由 `Icon/make_icon.swift` 用 CoreGraphics 画出 1024 px 原图（底板是连续曲率圆角，带玻璃边缘高光；两块板有投影、上沿亮边和下沿厚度，朱红板半透明）。改了画法后运行 `Icon/make_icns.sh` 重新生成 `Icon/AppIcon.icns`（同时留一张 `Icon/AppIcon-1024.png` 预览），`build.sh` 会把它拷进 `Contents/Resources/`。`make_icon.swift` 里还保留了设计过程中的其他方案，传方案名即可渲染，例如 `ivory-duo`、`glass-navy`。

菜单栏图标是同样造型的单色模板图（`MenuBarIcon.swift`，18×18 pt，前板和后板之间留一道缝），随系统深浅色自动变色；录屏时换成红色录制图标。

访达或程序坞里还显示旧图标时，是系统图标缓存没刷新：把应用挪动一下位置或重新登录即可。

### 自测（不需要权限）

```bash
swift build && .build/debug/Myuxcc --selftest /tmp/selftest.png
```

先跑长截图拼接自测：合成带吸顶栏、吸底栏的长文档，按一串滚动位置（含停顿、回滚、一次滚过一屏）逐帧拼接，要求状态序列正确、结果与原文逐像素一致；另测「上面是等高重复列表」时每次滚一行仍能识别位移；再测内容上方叠一个悬浮圆形按钮（不透明、60% 半透明各一次），要求按钮只在末尾出现一次、结果逐像素一致，并打印每帧拼接耗时；另用纯色色带页面、每帧只滚 16 或 32 行（模拟高帧率下的触控板连续滚动，按钮大部分落在纯色上）再测一遍；测左侧有带纹理的固定侧栏时，侧栏旁的内容仍逐像素正确；测右侧 30% 宽、占上方四分之三高的吸附面板（如结账页摘要栏），每帧小步滚动时不能跟丢，结果逐像素等于「面板只在顶部出现一次、下方是页面背景」；再测从文档中间起步先向上滚到顶、来回晃动、再滚到底，结果与整篇文档逐像素一致（上滑步长有大有小，含比吸顶栏还短的，吸顶栏不能叠影）；再测暗底文字页（几种行样式到处重复），用快慢不一的步长先下后上再下，位移判断必须全部正确、结果逐像素一致，中途插入只有光标闪烁一类局部变化的帧，必须判为没有滚动；最后模拟聊天应用：底部是带图片缩略图的大输入框，下面一行有每帧都在转的加载图标（滚动之间也在转），要求两者只在末尾出现一次、结果逐像素一致。另测连续多帧对不上时能自动另起一段、继续拼接且不留黑条，帧尺寸变化被单独判为 `sizeMismatch`，以及深色聊天窗口（固定侧栏 + 吸底输入框 + 低纹理内容）里输入框只在末尾出现一次、首屏以下的固定列不被输入框颜色染成纯色块。
再用合成图像跑一遍所有标注工具并导出 PNG，用来检查裁剪、方向、马赛克和 Retina 像素倍率。

### 长截图录帧与回放（排查真实应用里的问题）

菜单栏图标 →「记录长截图帧（调试）」（或设置里的同名开关）打开后，每次长截图都会把抓到的每一帧存成 PNG，放在 `~/Library/Caches/Myuxcc/long-capture/<时间>/`。只保留最近 3 次记录，单次最多 6000 帧（约 30 fps 下 3 分钟），「打开记录文件夹」可以直接打开这个目录。帧里是当时屏幕上的内容，只存在本机，用完记得关掉开关。端到端测试不录帧，免得把自己的记录挤掉。

离线回放某次记录，逐帧打印判定结果并输出长图（不需要权限）：
```bash
.build/release/Myuxcc --replay "<记录目录>" /tmp/replay.png
```
回放和实时拼接走的是同一套代码，结果逐像素一致，已用端到端测试录下的帧核对过。

加 `--preview-at N`（可重复）把第 N 帧之后预览框的样子另存为 `<输出>.preview-N.png`。预览框和最终长图按同一规则绘制：已拼好的画布上，再用最上一屏、最下一屏覆盖尚未拿到干净内容的行，所以输入框等固定元素只出现在顶部和底部。

## 已知限制

- 选区不能跨显示器（每块屏独立框选）
- 窗口吸附只到窗口级（基于窗口列表，不需要辅助功能权限），不能吸附按钮等控件；菜单栏和 Dock 不参与吸附
- OCR 偶尔会漏掉个别汉字（实测「截图里的中文」有时识别成「截图里中文」），中文和数字之间的空格会被吞掉；这是系统 Vision 的识别结果，换新旧两套 Vision 接口结果相同。没有在截图上划选文字
- 系统 OCR 引擎会在**进程内**整个失效：每张图都返回 `TextRecognition.CRImageReaderError error 1`，底层是 `e5rt_execution_stream_operation_create_precompiled_compute_operation_with_options ... Code: 13`（神经引擎的预编译计算操作建不起来）。这不是图的问题，也不是全局故障——同时开一个新进程识别完全正常；但出问题的那个进程里再试多少次都没用，只有退出重开才恢复。现在的处理：① 识别前把截图重画成紧凑的 8 位 sRGB 位图（屏幕截图本身没有颜色空间名、行宽还带填充）；② 失败隔 150 ms 在本进程再试一次；③ 仍失败就把图交给常驻的 `--ocr-worker` 子进程识别（启动 5 秒后后台预热好，接管只要约 0.2 秒），子进程坏了会被杀掉换新的，**应用不用重启、钉图也不丢**；④ 连子进程也失败才提示「系统文字识别引擎暂时不可用」。1–2 像素的误点选区直接提示「选区太小」，不再弹英文 NSError
- 截图翻译要 macOS 26 以上，并且要先在「系统设置 › 通用 › 语言与地区 › 翻译语言」下载对应语言包；没下载时只提示去哪里下，不会自动下载。系统翻译不看上下文，单个词可能译偏（实测「Close the window」译成「关闭窗户」、「screenshots」译成「屏幕注释」）。覆盖翻译在纯色背景上效果最好，照片或渐变背景上盖字的色块会比较明显；译文比原文长很多时字会缩小，最小到原字号的一半左右，还放不下就往下延伸盖住下面的内容；图标、按钮上没识别到的小字不翻译
- 颜色只有 8 种预设，没有自定义取色和透明度
- 默认快捷键 `⌃X` 是全局占用的：终端里 nano 退出用的 `^X`、emacs 的 `^X` 前缀会被它拿走，常用的话请在设置里换掉
- 剪贴板和文件共用一个列表和个数上限，复制得多时较早的文件会被挤到废纸篓；只记纯文字（不保留 RTF 格式）
- 剪贴中转板界面只有中文（MacFileRelay 原来的中英切换没搬）；拖出时是复制，拖到访达也不会把文件从剪贴中转板移走；去掉了原来的图片悬停大图和空格 Quick Look，改用左侧预览栏；`⌃X` 是全局快捷键，会抢掉终端里 nano 的退出键和 emacs 的 `⌃X` 前缀，冲突时在设置里换一个
- 剪贴中转板的内容都存成文件，内存里只有条目信息（文字最多读 2000 字）和缩略图缓存（上限 64 MB）；面板隐藏时不重建列表，预览图最长边 1200 像素。复制大图时内存仍会短暂冲高：8000×6000 的 TIFF 实测峰值约 390 MB（原始 TIFF 加解码后的图），只是转换放到了后台线程，不卡界面；粘贴图片条目时 TIFF 只在别的应用要时才生成
- 2026-10-25 起旧的剪贴板历史面板换成了剪贴中转板；以前记下的历史仍在 `~/Library/Application Support/Myuxcc/Clipboard/`，没有删除
- 2026-10-26 应用从 ScshootDemo 改名为 Myuxcc（bundle ID 从 `com.yuxccu.scshootdemo` 改为 `com.yuxccu.myuxcc`）。第一次以新名字启动时自动迁移：旧设置复制过来（新名字下已有的不覆盖），`Application Support/ScshootDemo` 合并进 `Application Support/Myuxcc`，`~/Movies/ScshootDemo 录屏` 改名为 `~/Movies/Myuxcc 录屏`；只做一次，不删旧设置。因为 bundle ID 变了，屏幕录制、辅助功能权限和「登录时自动打开」要重新开一次
- 长截图只支持竖向、手动滚动（不做自动滚动和横向）；最长 32000 像素且总像素不超过 3000 万；随滚动变形或淡入淡出的浮层、动画和懒加载内容不保证正确（固定元素按「位置不变」判定）；一次滚动距离很大时，内容只被看到一次，判定余量会变小；连续多帧对不上后自动另起的一段是有损恢复，接缝处内容会缺失（HUD 会提示，建议取消后重截）；大选区的关键帧拼接仍可能超过 30 fps 预算，向上滚出已截范围时 prepend 整块画布的成本随画布线性增长；固定侧栏（内容滚动时整列不动）只按第一屏的样子出现一次，下方用第一屏最后一个**内容行**的颜色填充，所以长图下半部分的侧栏区域会是纯色而非重复的侧栏内容；深色低纹理界面上固定元素边缘可能残留几行杂色细线
- 标注不能多选、不能调层级；文字标注只能移动和重编辑，不能拖手柄缩放字号
