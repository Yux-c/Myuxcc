# Myuxcc

原生 macOS 截图、长截图、OCR 文字识别、截图翻译、区域录屏与剪贴中转板工具。
使用 Swift + AppKit + ScreenCaptureKit 编写，零第三方依赖。

## 核心功能

| 功能 | 说明 |
|---|---|
| **快速截图** | 全局快捷键（默认 `⌃A`）冻结多屏画面，支持智能窗口吸附、放大镜取色（按 `C` 复制色值）、自由框选 |
| **丰富标注** | 矩形、椭圆、箭头、画笔、荧光笔、文字、马赛克；支持颜色与粗细切换、PPT 式选中移动/缩放、撤销/重做（`⌘Z` / `⇧⌘Z`）及数字键 `1`–`9` 快捷切换 |
| **滚动长截图** | 框选后锁定区域，手动上下滚动即可实时拼接，自动去除吸顶栏、吸底栏、固定侧栏与悬浮按钮 |
| **OCR 文字识别** | 基于系统 Vision 框架离线识别中英文，支持在原图上直接划选复制文字 |
| **截图翻译** | 基于系统 Translation 框架离线翻译，支持原位覆盖译文（保留原底色与字色，按 `T` 切换原文/译文）与文本对照翻译（需 macOS 26+） |
| **桌面钉图** | 将截图贴在桌面置顶参考，支持滚轮缩放、`⌥`+滚轮调节透明度、右键 OCR / 翻译 / 保存 |
| **区域录屏** | 选区直录 H.264 MP4（最高 30 fps，Retina 原生分辨率），支持计时条控制与菜单栏快捷停止 |
| **剪贴中转板** | 默认按 `⌃X` 或拖拽文件晃动鼠标呼出；合并剪贴板历史（文字/图片/文件）与文件暂存架，支持搜索过滤、空格预览、点击自动粘贴并恢复原剪贴板、拖拽发送 |

## 构建与运行

**环境要求**：macOS 14+，Xcode 命令行工具。

```bash
# 编译 Release 版本并安装到 /Applications/Myuxcc.app
./build.sh

# 启动应用
open /Applications/Myuxcc.app
```

> 仅编译不安装可使用 `./build.sh --no-install`。首次使用请按系统提示在「系统设置 › 隐私与安全性」中授予**屏幕与系统录音**及**辅助功能**（用于中转板自动粘贴）权限。

## 常用快捷键

- `⌃A`：开始截图（可在设置中修改）
- `⌃X`：打开 / 收起剪贴中转板（可在设置中修改）
- `↩` / `⌘C` / 双击：复制截图到剪贴板
- `⌘S`：保存截图到指定目录
- `1`–`7`：切换标注工具，`8` / `9`：撤销 / 重做
- `C`：框选前复制光标处色值
- `T`：钉图翻译后切换显示原文 / 译文
- `Esc`：取消选中 / 退出截图 / 关闭钉图

## 目录结构

- `Sources/Myuxcc/`：核心源码（截图、标注、长截图拼接、OCR、翻译、录屏、`Shelf/` 剪贴中转板）
- `Icon/`：CoreGraphics 图标生成脚本与资源
- `build.sh`：一键打包与签名脚本
